# Version {{VERSION}}
## Build {{BUILD}}

**支払いリクエスト 🧾**
支払いリクエストで ecash を請求・送金できるようになりました。リクエストを QR コードで共有して Nostr の DM で受け取るか、2台の端末を近づけるだけで NFC による非接触決済ができます。

**全く新しいオンボーディングフロー 🗒️**
オンボーディング画面を一から再設計し、シードフレーズからの復元にも対応しました。

**ミントリストのバックアップ 📡**
NUT-27対応により、ミントリストを自分で保存する必要がなくなりました。ウォレットが暗号化されたバージョンを自動的にNostrリレーへバックアップします。
この機能は対応するすべてのウォレット間で動作します。
