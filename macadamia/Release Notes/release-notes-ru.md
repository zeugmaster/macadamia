**Запросы платежей 🧾**
Теперь ты можешь запрашивать и отправлять ecash с помощью запросов платежей. Поделись запросом в виде QR-кода и получай оплату через личные сообщения Nostr — или просто поднеси два телефона друг к другу для бесконтактной оплаты через NFC.

**Совершенно новый процесс онбординга 🗒️**
Экран онбординга полностью переработан и теперь поддерживает восстановление из сид-фразы.

**Резервное копирование списка минтов 📡**
С поддержкой NUT-27 тебе больше не нужно сохранять список минтов — кошелёк автоматически загружает зашифрованную копию на Nostr-реле.
Это работает между всеми кошельками, которые поддерживают функцию.
